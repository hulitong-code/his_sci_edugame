## 如何添加图片 / How to Add Images

### 方法1: 使用现有图片
1. 找到或创建对应的图片文件
2. 将图片重命名为对应的文件名（如 `evaporation.png`）
3. 将图片放入 `questions/images/` 目录
4. 重启游戏即可看到图片

### 方法2: 从网络下载
可以从以下免费教育资源网站下载相关图片：
- Pixabay (https://pixabay.com)
- Unsplash (https://unsplash.com)
- Pexels (https://www.pexels.com)
- OpenClipart (https://openclipart.org)

**注意**: 请确保您有使用这些图片的权限。

### 方法3: 自己创建
- 使用绘图软件（如 PowerPoint, Canva, GIMP）
- 创建简单的示意图或图表
- 保存为 PNG 格式

## 图片要求 / Image Requirements

- **格式**: PNG, JPG, JPEG, GIF, BMP
- **推荐大小**: 400x300 像素或更小
- **文件大小**: 建议小于 500KB
- **内容**: 清晰、教育性强的图片
